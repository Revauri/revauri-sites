# revauribuilds-site

One-page trust site for https://revauribuilds.com — for people who received an email from `@revauribuilds.com` and typed the domain into a browser. Shows the jobs a Revauri AI hire can take. The product homepage is https://revauri.ai; booking is at https://revauri.ai/book.

- `docs/copy.md` — locked page copy
- `docs/design.md` — visual design spec (palette, type, tokens)

## Develop

```bash
npm run dev
npm run build
```

Do not deploy from this repo. DNS and hosting are handled separately.
